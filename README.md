# "Guess the Number" Mini-Project

## Description
A simple console game written in **Python**, where the computer selects a random number between 1 and 100, and the player tries to guess it. The game guides the user with custom colored messages and protects against invalid text inputs using the `.isdigit()` method.

## Game Features and Colors
* **Green Color:** Means you guessed the correct number and won the game!
* **Blue Color:** Appears when your guess is **too high** (higher than the computer's number).
* **Red Color:** Appears when your guess is **too low** (less than the computer's number).
* **Input Validation:** Prevents crashes if the player enters text instead of numbers.
